# tl-daily-note — 每日日志生成器

生成今天的结构化 Markdown 日志模版，直接输出，无需额外提问。

## 执行步骤

### 1. 获取当前日期

```bash
date "+%Y-%m-%d %A"
```

用获取到的日期作为日志标题（中文星期，例：`2026-05-03 星期日`）。

### 2. 输出模版

严格按照以下结构输出，不要增减板块，不要添加说明文字，直接给出可粘贴的 Markdown：

---

```markdown
# {YYYY-MM-DD 星期X}

## 昨日复盘

### 做了什么

### 在思考什么

### 第三方洞见

### 第三方建议

---

## 半九十
> 已经投入了不少时间、但因为拖延没有收尾的事。现在就推它一把。

- [ ] 

---

## 今日一件事
> 今天结束时，做到这件事就算成功：


---

## TODO项

- [ ] 
- [ ] 
- [ ] 

---

## Time
> 记录各时间段实际在做什么，帮助复盘时间去向

- 09:00 
- 11:00 
- 14:00 
- 16:00 
- 20:00 

---

## Think
> 今天涌现的想法、疑问、值得继续深想的事

```

---

### 3. 输出规范

- **直接输出模版**，不要在前面加"好的，以下是你的日志模版："之类的废话
- **日期和星期自动填入**，不留占位符
- 所有内容区块保持空白，让用户自己填写
- 输出格式为纯 Markdown 代码块，用户可直接复制粘贴到任何笔记工具
- 如果用户在触发时附带了内容（例如 `/tl-daily-note 今天要准备面试`），将该内容自动填入 **今日一件事** 板块

### 4. 板块说明（仅供 AI 理解用途，不输出给用户）

| 板块 | 用途 |
|------|------|
| 昨日复盘 | 回顾昨天，通过第三方视角获得洞见 |
| 半九十 | 专门盯住"90% 完成但卡住"的事，强制收尾 |
| 今日一件事 | 今日最高优先级，只允许一件，避免 TODO 散焦 |
| TODO项 | 今日任务清单 |
| Time | 时间流水账，记录每个时间块实际在做什么 |
| Think | 今日新想法、疑问、值得深想的事 |
