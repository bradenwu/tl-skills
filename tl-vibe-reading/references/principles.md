# Vibe Reading principles

Vibe Reading is for useful reading: acquiring knowledge to solve problems, make decisions, or build reusable models. It is not meant to optimize pleasure reading.

Core idea: learning is compression, not transmission. AI can accelerate transmission and mechanical search, but the user must perform judgment, compression, application, and explanation.

Common failures:
- One-click summary creates completion theater: the user receives compressed text without cognitive hooks.
- Hard-cover-to-cover reading wastes time on low-ROI pages.
- AI hallucination turns book notes into an imagined version of the source.
- Unanchored AI output drifts into broad related content and overwhelms the user.

Operating boundary:
- AI handles pseudo-learning: searching, locating, comparing, organizing, paraphrasing auxiliary material, checking against source.
- User handles real learning: setting aims, deciding priorities, writing current understanding, applying knowledge, teaching it back.

The anchor is always the user's written need or written understanding. If the anchor is absent, create it before producing substantial content.
